About This File

Option 1 — Share the File Directly
The simplest option. No hosting needed.
1Save this HTML file to your computer (File → Save As, or right-click → Save)
2Open it anytime by double-clicking — it will open in your default browser
3Share it via email attachment, Google Drive, Dropbox, OneDrive, or USB drive
4Recipients open it the same way — double-click in their browser
⚠️ Some email providers block .html attachments. If so, zip the file first, or share via a cloud link (Google Drive, Dropbox).
Option 2 — GitHub Pages (Free, Permanent URL)
GitHub Pages gives you a free permanent public URL in about 5 minutes. No coding experience required.
Step-by-step:
1Go to github.com and create a free account (if you don't have one)
2Click the + icon (top right) → New repository
3Name it: assessment-exam (or any name). Set it to Public. Click Create repository
4Click uploading an existing file → drag and drop this HTML file → rename it to index.html → click Commit changes
5Go to Settings → Pages (left sidebar) → under Source, select Deploy from a branch → main → / (root) → click Save
6Wait ~2 minutes. Your exam will be live at:
https://YOUR-USERNAME.github.io/assessment-exam/
✓ That URL is permanent, free, mobile-friendly, and shareable with anyone. No login required to view it.
💡 To update the exam later: go to your GitHub repo → click the file → click the pencil (edit) icon → paste updated content → Commit. Changes go live in ~1 minute.
Option 3 — Netlify Drop (Fastest, Free)
No account required for a temporary link. Create a free account for a permanent one.
1Go to drop.netlify.com in your browser
2Drag and drop this HTML file onto the page
3Your exam is instantly live at a random URL like: https://random-name.netlify.app
4Create a free Netlify account to claim a permanent, custom URL and enable easy updates
💡 Netlify is the fastest option — from file to live URL in under 60 seconds.
Option 4 — Other Hosting Platforms

Create a page at sites.google.com → Insert → Embed → paste the file URL. Best if your team already uses Google Workspace.

SharePoint / City Intranet Internal

Upload the HTML file as a document or embed it in a SharePoint page. Ideal for internal OPA / city employee access only.

Squarespace / Wix / Webflow Paid plans

Use a Custom Code or Embed block to host the exam on an existing website. Requires a paid plan for custom HTML embedding.

LMS (Canvas, Moodle, Blackboard, TalentLMS) Varies

Upload as an HTML page or external resource. Allows tracking of completions if the LMS supports it. Best for formal training programs.
